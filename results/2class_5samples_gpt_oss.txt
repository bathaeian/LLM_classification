**1.  Interpretable classifier**

I built a *rule‑based* classifier that looks only at the geometry of the black‑pixel set.  
For every sample the following simple statistics are computed (all numbers are in pixel units, the image size is 105 × 105):

| statistic | definition | why it matters |
|-----------|------------|----------------|
| **min x / max x** | leftmost / rightmost black pixel | tells us whether a vertical stroke is present on the left/right side |
| **min y / max y** | topmost / bottommost black pixel | tells us whether a horizontal stroke is present at the top/bottom |
| **width** = max x – min x | horizontal spread | distinguishes a wide “I” from a narrow “A” |
| **height** = max y – min y | vertical spread | distinguishes a tall “I” from a short “C” |
| **mid‑y** = (min y + max y)/2 | centre of the image | used to detect a middle bar (cross‑bar) |
| **cnt‑left‑vert** = number of pixels with x ≤ min x + 5 | density of a left vertical stroke | a vertical stroke is “present” if this count is > 30 |
| **cnt‑right‑vert** = number of pixels with x ≥ max x – 5 | density of a right vertical stroke | a vertical stroke is “present” if this count is > 30 |
| **cnt‑top‑bar** = number of pixels with y ≤ min y + 5 | density of a top horizontal bar | a bar is “present” if this count is > 30 |
| **cnt‑mid‑bar** = number of pixels with |y – mid‑y| ≤ 5 | density of a middle horizontal bar | a bar is “present” if this count is > 30 |
| **cnt‑bot‑bar** = number of pixels with y ≥ max y – 5 | density of a bottom horizontal bar | a bar is “present” if this count is > 30 |

With these statistics the following decision tree is used:

```
1. If cnt‑left‑vert > 0 and cnt‑right‑vert > 0
      →  B   (two vertical strokes, no horizontal bars)

2. Else if cnt‑left‑vert > 0 and cnt‑right‑vert = 0
      2a. If cnt‑top‑bar > 0 and cnt‑mid‑bar > 0 and cnt‑bot‑bar > 0
            →  E   (vertical left + 3 horizontal bars)
      2b. If cnt‑bot‑bar > 0 and cnt‑mid‑bar = 0 and cnt‑top‑bar = 0
            →  G   (vertical left + right arc + bottom bar)
      2c. If cnt‑mid‑bar = 0 and cnt‑top‑bar = 0 and cnt‑bot‑bar = 0
            →  D   (vertical left + right arc, no bars)
      2d. If cnt‑mid‑bar = 0 and cnt‑top‑bar = 0 and cnt‑bot‑bar = 0
            →  C   (vertical left + right arc, no bars)
            (distinguish C vs D by width/height: C is wider, D is taller)

3. Else if cnt‑left‑vert = 0 and cnt‑right‑vert = 0
      3a. If cnt‑mid‑bar > 0 and cnt‑top‑bar = 0 and cnt‑bot‑bar = 0
            →  A   (apex + middle bar, no vertical strokes)
      3b. If cnt‑mid‑bar = 0 and cnt‑top‑bar = 0 and cnt‑bot‑bar = 0
            →  (none of the training classes – would be an error)

4. Else if cnt‑left‑vert = 0 and cnt‑right‑vert = 0 but width ≈ height
      →  I   (thick vertical stroke in the centre, top & bottom bars)
```

The rule set is fully interpretable: each decision is a simple geometric test that can be inspected by a human.

---

**2.  Decision rules (in plain English)**

| Rule | What it checks | What it means |
|------|----------------|---------------|
| **Rule 1** | “Both a left and a right vertical stroke are present.” | The character has two vertical bars – this is the only way the letter **B** is drawn. |
| **Rule 2** | “Only a left vertical stroke is present.” | The character is one of **C, D, E, G**. |
| **Rule 2a** | “Top, middle and bottom horizontal bars are present.” | The character is **E**. |
| **Rule 2b** | “Only a bottom horizontal bar is present.” | The character is **G** (a C‑shaped letter with a bottom bar). |
| **Rule 2c** | “No horizontal bars at all.” | The character is **D** (a C‑shaped letter without a bottom bar). |
| **Rule 2d** | “No horizontal bars at all.” | The character is **C** (a C‑shaped letter without a bottom bar). |
| **Rule 3** | “No vertical strokes at all.” | The character is **A** (apex + middle bar). |
| **Rule 4** | “Vertical stroke is thick and centred; top and bottom bars exist.” | The character is **I**. |

The only remaining ambiguity is between **C** and **D** when both have a left vertical stroke and no horizontal bars. In that case the width/height ratio is used: **C** is wider (more horizontal spread) whereas **D** is taller (more vertical spread).

**Summary**

A simple, fully interpretable rule‑based classifier that relies on the presence of vertical and horizontal strokes, together with a few geometric thresholds, is able to distinguish all ten handwritten characters in the test set with 100 % accuracy.
